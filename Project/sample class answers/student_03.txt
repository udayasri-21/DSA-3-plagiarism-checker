Hashing is a technique that converts a key such as a name or a number into a small integer called a hash value. The hash value tells us the exact slot of the table where the data should be stored. Because we jump straight to that slot, searching takes constant time on average instead of checking every item one by one. When two keys give the same hash value a collision happens and we solve it with chaining or open addressing. I think hashing is also used to protect passwords.
